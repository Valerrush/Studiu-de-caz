Ce este Git?

Git este un sistem de control al versiunilor creat de Linus Torvalds. El permite urmărirea modificărilor din codul sursă și colaborarea eficientă între programatori.

Ce este GitHub?

GitHub este o platformă online care găzduiește proiecte ce utilizează Git, oferind interfață web, issue tracking, wiki și multe instrumente de colaborare.
